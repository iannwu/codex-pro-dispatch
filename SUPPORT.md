# Support

## Questions and compatibility

Read [README.md](README.md), [docs/compatibility.md](docs/compatibility.md), and [docs/acceptance.md](docs/acceptance.md) first. For reproducible, non-sensitive bugs, open a GitHub issue using the bug form.

Include:

- Codex Pro Dispatch version
- ChatGPT/Codex app version and build
- macOS version and architecture
- confirmation that the failure occurred in the official ChatGPT desktop app, not the web app, CLI alone, or an IDE extension
- the missing or failing semantic capability
- whether the assignment was prompt-only or required repository access
- for repository work, whether the GitHub connector exposed read or write actions (omit repository names)
- whether the required starting commit was already visible on the remote
- redacted command output and reproduction steps

Never post conversation IDs, assignment receipts, prompts, responses, credentials, private repository names, or logs containing account data.

## Security

Use the private vulnerability-reporting process in [SECURITY.md](SECURITY.md). Do not report vulnerabilities in a public issue.

## Scope

This is an independent open-source project, not an OpenAI support channel. Help is best-effort. Questions about ChatGPT accounts, billing, model availability, or the official app itself belong with OpenAI support.
