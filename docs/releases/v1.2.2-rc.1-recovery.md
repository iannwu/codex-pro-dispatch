## Verification limits and stable-release work

The native reader returns a processed history summary, not original message
bytes or authoritative generation-finality evidence. Accepted receipts explicitly
report `bounded_native_summary`, `source_bytes_verified=false`, and
`generation_finality_verified=false`. Missing truncation flags remain null.
Independent fixture and Git checks establish exactness only for those specific
deliverables. The app build changed since the previous release; an app update
was not proven to have caused the failure.

The full [A–L native matrix](../acceptance.md) must still pass on the final
candidate before a stable release. This recovery run does not re-certify app
interruption/restart boundaries or foreground behavior, and its 26,236-byte
fixture does not satisfy the matrix's greater-than-30,000-character gate.
Automated coverage of cooldowns, malformed summaries, stale reads, and privacy
does not substitute for the remaining live matrix cases.
