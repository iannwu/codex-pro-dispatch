## Reproducible long fixture

Use sections S=1..5. Section 1 contains N=001..125; sections 2..5 each contain
N=001..080. Each line is:

```text
RECOVERY-S{S}-{N}|ABCDEFGHIJKLMNOPQRSTUVWXYZ|abcdefghijklmnopqrstuvwxyz|0123456789|
```

Join lines within each section with LF, without leading/trailing LF. Concatenate
the five sections without additional separators. Verified SHA-256:
`8710585695d29072696e297ac25fb09a7fb545029349015496b3959b3b7de558`.

Computer-use access to the ChatGPT/Codex app is blocked in this environment.
App restart and the user-visible foreground checks therefore require a manual
step. Do not bypass that restriction, resend an armed assignment, or promote the
prerelease while these gates remain incomplete.

and generation-finality verification remain false.
